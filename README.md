# Swap Bot (Android)

يبدّل للكليرك -> يفعّل الاسكل -> يرجّع الاستاف تلقائياً.

## البناء
1. افتح مجلد المشروع في Android Studio (File > Open) وانتظر Gradle Sync.
2. وصّل جوالك (تفعيل USB debugging) واضغط Run، أو Build > Build APK(s).
3. أندرويد 11 أو أحدث مطلوب.

## الاستخدام
1. افتح التطبيق > "فعّل خدمة الوصول" > Swap Bot > تشغيل.
   (أندرويد 13+ لو طلع "إعداد مقيّد": معلومات التطبيق > ⋮ > السماح بالإعدادات المقيّدة.)
2. "أظهر اللوحة العائمة" وارجع للعبة.
3. اسحب الدوائر: 1 فوق زر تبديل السلاح، 2 فوق اسكل الكليرك، 3 فوق أيقونة التفعيل (وهي شغالة).
4. اضغط "معايرة" ثم "▶ ابدأ".
